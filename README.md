# Threadex

Lightweight requirement-to-goal harness for Codex.

Threadex keeps the default agent workflow thin:

1. Clarify ambiguous intent.
2. Draft verifiable requirements.
3. Convert the requirements into a compact Codex `/goal`.
4. Verify the agent result against concrete evidence.
5. Preserve useful learnings for the next run.

The plugin is intentionally small. It should help the user write better inputs and verify outputs without adding a heavy automation layer.
