# Threadex 0.5.0 evaluation

Evaluated on 2026-11-03 before publication. This is a smoke report, not a
cross-model reliability benchmark.

## Method

Ten independent agents received only a prepared request, skill catalog, and raw
fixtures in separate temporary workspaces. No expected answers, case rubrics, or
parent conversation were supplied. Model and reasoning settings were inherited
from the evaluating host; per-trial resolved model metadata was not captured.
The parent graded the returned results and independently inspected fixture diffs.
No live external systems were used by the trial tasks.

## Results

| Case | Result | Observed behavior |
| --- | --- | --- |
| explanation_only | PASS | Two-sentence comparison explanation; no generated artifacts. |
| clarify_from_repo | PASS | Used README decisions; no redundant question or generated requirements. |
| specify_values | PASS | Preserved two retries after the first request, three-second interval, success stop and exhausted-error behavior; chat only. |
| goal_draft_only | PASS | Returned a compact /goal contract with actual test command and blocked behavior; no implementation. |
| review_only | PASS | Reported equality rejection with file/line evidence and the failing existing test; source unchanged. |
| verify_stale_ci | PASS | Rejected revision-a CI as proof for revision-b; mapped current greater/equal/lower cases and returned FAIL. |
| review_and_fix | PASS | Established the defect, fixed equality, added a zero-value test and completed four passing tests without another approval stop. |
| verify_and_fix | PASS | Established initial failure, repaired equality and returned final PASS with six passing tests. |
| compound_summary | PASS | Returned a scoped callback-test learning, qualified the ten-run evidence, and wrote no learning files. |
| specify_then_implement | PASS | Stated acceptance criteria, continued to repair and completed six passing tests without stopping at a spec. |

All seven non-repair workspaces retained their original fixture files and created
no user artifacts. In the three repair trials, requirements were unchanged and
all original test functions remained intact (AST comparison); only source and
additive test coverage changed. The parent independently reran all three suites
(4, 6, 6 tests) and checked 225 non-negative balance/cost pairs per repaired
implementation against the requirement.

## Package checks

- 12 validator/preparation regression tests passed.
- All six skills passed the installed skill-creator quick validator.
- Threadex static validator passed with `THREADEX_RELEASE_VERSION=0.5.0`.
- Final diff whitespace check passed.

## Limits

Prepared trials expose a supplied catalog; they do not prove native implicit
plugin discovery, custom-agent registration, or model inheritance in every Codex
client. Model selection and sandbox inheritance follow the documented host
contract; removing ineffective agent settings does not create stronger isolation.
These trials did not compare the old and new plugin on a fixed model, so they do
not establish a measured improvement rate. Fresh installed-plugin checks belong
to deployment verification and should be reported separately.
